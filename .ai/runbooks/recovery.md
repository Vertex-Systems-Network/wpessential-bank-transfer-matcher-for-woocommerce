# Development recovery

1. Run `git status --short --branch` and `git log -5 --oneline`, then compare them with .ai/state.json.
2. Read the evidence for the active task and rerun its recorded command on a disposable installation.
3. Recover missing tooling before changing compatibility claims. Use the documented Playground version, then reproduce concurrent ledger bugs in a disposable MySQL/MariaDB installation.
4. Quarantine suspected import corruption, preserve evidence and review the ledger through audit events before a deliberate correction.
5. If Pro lacks Free, activate a compatible Free version and re-run dependency checks.
6. If Git diverges, fetch and inspect both histories. Preserve local edits and use a regular merge or a clean worktree.
