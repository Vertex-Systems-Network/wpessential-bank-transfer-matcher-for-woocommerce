# WPEssential Bank Transfer Matcher for WooCommerce

Development preview with a WooCommerce admin entry point.

## Requirements

WordPress 7.0+, PHP 8.3+, and WooCommerce 10.8+ are minimum requirements for the development build.

## Development installation

Activate WooCommerce before installing the edition ZIP. Use the WordPress Plugins screen to upload and activate the ZIP.

## Verified preview scope

- WooCommerce admin entry point with role-based access.

## FAQ

### Is this ready for a live store?

This is a development preview. Install it on a disposable WordPress site.

## Support and privacy

Use the project repository's issue tracker for development feedback. Keep bank statements, customer information, and credentials out of public reports. Use synthetic data when reporting a problem.
